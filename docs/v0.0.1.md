# Jabfy V0.0.1

L'orchestration et le guide de lancement appartiennent à **jabfy-deploy**.
Depuis le dépôt voisin `jabfy-deploy`, lancer `python3 scripts/start.py`, puis ouvrir
http://127.0.0.1:8080. Voir `jabfy-deploy/docs/v0.0.1.md` pour les prérequis, les tests
et les commandes d'arrêt.

Ce dépôt fournit la maison virtuelle, l'interface et son image Docker. Il ne lance
pas Core ni Ollama. Pour cette V0.0.1, Guard et Bus sont des bibliothèques intégrées
au runtime de simulation ; ils ne sont pas encore des services réseau séparés.
